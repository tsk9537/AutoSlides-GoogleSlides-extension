# AutoSlides - Google Slides Auto-Presenter Chrome Extension

## How to Install in Google Chrome, Brave, or Microsoft Edge:

1. Extract this ZIP file into a folder on your computer.
2. Open your browser and go to the extensions page:
   - Chrome: `chrome://extensions`
   - Brave: `brave://extensions`
   - Edge: `edge://extensions`
3. Enable **"Developer mode"** (toggle located in the top-right corner).
4. Click **"Load unpacked"** and select the unzipped folder.
5. Open any Google Slides presentation (e.g. `https://docs.google.com/presentation/d/.../edit`).
6. Click the AutoSlides extension icon in your Chrome toolbar (or press **Alt + P**).
7. Configure your desired interval (seconds or minutes), click **"Start Auto-Slideshow"**, and enjoy!
